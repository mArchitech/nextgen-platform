# Nextgen platform

## Overview

This project documents my journey of building a production-style cloud-native application from scratch.

The goal is to learn and demonstrate modern software engineering, platform engineering, DevOps and cloud practices through a hands-on project.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions
- Terraform
- Kubernetes
- Prometheus
- Grafana

## Roadmap

### Phase 1
- Create FastAPI application
- Add root endpoint
- Add health endpoint

### Phase 2
- Dockerize application
- Create Docker Compose configuration

### Phase 3
- Integrate PostgreSQL
- Implement CRUD operations

### Phase 4
- Configure GitHub Actions
- Add automated testing

### Phase 5
- Provision infrastructure using Terraform

### Phase 6
- Deploy to Kubernetes

### Phase 7
- Add monitoring with Prometheus and Grafana

### Phase 8
- Implement security controls and scanning
